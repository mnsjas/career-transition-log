# 予実差異分析ダッシュボード（Power BI）
## 概要
売上の予算と実績を比較し、どのセグメント・どの月で差異が生じているかを把握するためのダッシュボード。
<img width="1303" height="732" alt="image" src="https://github.com/user-attachments/assets/fd909db0-f2cc-4d01-b15c-88ce43dfb76e" />

## データ
- 実績：Microsoft Power BI 公式サンプル「Financial Sample」（2013年9月〜2014年12月）
- 予算：自作（Budget.xlsx）

## 予算の設定方法（仮定）
2013年のデータは9〜12月のみのため、セグメント別の月平均売上に、セグメントごとの成長率の仮定（〔3〜10〕%）を掛けて2014年の月次予算を設定した。月ごとの配分は均等。

## データモデル
実績（Fact_Sales）と予算（Fact_Budget）の2つのファクトテーブルを、日付・セグメント・製品・国のディメンションでつないだスター型スキーマ。予算はセグメント×月の粒度。
<img width="1264" height="757" alt="image" src="https://github.com/user-attachments/assets/c7a85f71-e9be-469c-8a4c-2601c8ba24eb" />

## 主なDAXメジャー
- 予実差異、予実差異率、達成率
- 年度累計（TOTALYTD）、前年比（SAMEPERIODLASTYEAR）
- 損益ブリッジ（SWITCHで総売上→値引き→原価→利益の段階を表示）

## デザインの意図

- **概要から詳細へ、上から下に読める構成**
  予実サマリーは「KPI（全体の結論）→ 月別推移・セグメント別差異（どこで差が出たか）→ セグメント×月の差異率（詳細）」の順に配置し、上から読むだけで結論から原因まで辿れるようにした。

- **色に意味を持たせ、使う色を絞る**
  実績はメインの青、予算は参照値としてグレーで控えめに表示。赤・緑（青）は予実差異の未達・超過にのみ使い、色が出ている箇所＝注目すべき箇所となるようにした。

- **タイトルに結論を書く**
  各グラフのサブタイトルには「何のグラフか」ではなく「何が分かるか」を記載し、グラフを読み解く前に要点が伝わるようにした。

- **数値は読み手が比較しやすい形式に統一**
  金額は百万（M）単位、比率はパーセント（小数1桁）に統一。

- **データの粒度に合わせてフィルターを制限**
  予算はセグメント×月の粒度で作成しているため、予実サマリーにはセグメントのスライサーのみを配置した。製品や国で絞り込むと予算が絞り込まれず、誤った比較になるため。製品・国別の分析は、予算を使わない収益性分析のページで扱った。

- **収益性分析は「どこで利益が削られているか」を示す**
  総売上 → 値引き → 原価 → 利益をウォーターフォール図で表し、利益の減少要因を一目で把握できるようにした。値引き区分別・製品別の利益率は降順に並べ、比較しやすくした。また、予実サマリー（2014年のみ）と数値を取り違えないよう、ページタイトルに対象期間を明記した。

## 制約
- 予算は仮定に基づく値であり、実在の計画ではない
- 前年比は2014年9〜12月のみ算出可能

## 使用ツール
Power BI Desktop（Power Query、DAX）、Excel
